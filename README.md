# КЕМЕТ — мифология Древнего Египта

Интерактивная энциклопедия мифологии Древнего Египта, построенная ИИ-командой за одну ночь (28.10.2026) по заданию Шефа. Аналог и «южный брат» проекта «Скандик» (скандинавская мифология): https://olegvnovikov75.github.io/scandic/

## Запуск
```bash
cd ~/Projects/egypt
python3 -m http.server 8300
# → http://localhost:8300
```

## Структура
- `index.html` — главная: солнце, «чёрная земля», мироздание, река времени.
- `gods.html` + `gods/` — пантеон (17 профилей богов).
- `symbols.html` + `symbols/` — великие символы (анх, уджат, джед, тьет, уас, скарабей).
- `death.html` + `death/` — мумификация, канопы, Книга мёртвых, Дуат, Суд, отверзание уст, саркофаги, поля Иалу.
- `arch.html` + `arch/` — мастабы, Джосер, Гиза, сфинкс, Карнак, Луксор, Абу-Симбел.
- `cats.html` + `cats/` — кошки: Бастет и бытовая кошка.
- `compare.html` — «Египет × Скандинавия» (по аналитическому материалу Шефа 12.10.2026).
- `about.html`, `sources.html`, `glossary.html`, `404.html`.
- `css/style.css` — тема «Ночная пустыня» (ляпис + золото), `js/main.js` — меню, активный пункт, звёзды.
- `templates/page-skeleton.html` — канон страницы; `gods/ra.html` — эталон.
- `scripts/check_links.py` — проверка внутренних ссылок и «щуплых» страниц.
- `chip_log.md` — журнал партий Чипа; `PLAN.md` — карта сайта и правила.

## Роли
- **Гаечка** (старшая, модель 87G на Стриксе): каркас, дизайн, главная, каталоги, кошки, сравнение, приёмка.
- **Чип** (контент-автор, модель 27B на X99): партии страниц богов, загробного мира, архитектуры и символов — с фактчекингом по ru.wikipedia.

## QA
После каждой партии: `python3 scripts/check_links.py` — ноль битых внутренних ссылок, страницы не тоньше 4000 байт, выборочная вычитка текста.
