## Конвенции страницы (КАНОН — смотреть эталон `gods/ra.html` и `templates/page-skeleton.html`)

1. Один файл = одна страница, русский язык, `<html lang="ru">`, `<meta charset="utf-8">`.
2. Подключаются: `../css/style.css` (в корне — `css/style.css`), `../js/main.js` (defer).
3. Навигация (скелет в шаблоне): логотип «𓋹 КЕМЕТ» → `../index.html`; ссылки: Боги `gods.html`, Символы `symbols.html`, Смерть `death.html`, Архитектура `arch.html`, Кошки `cats.html`, Египет×Скандинавия `compare.html`, Источники `sources.html`; справа переключатель «Север» → https://olegvnovikov75.github.io/scandic/
4. Тело: `<header class="page-hero">` (хлебные крошки, h1, подзаголовок-эпитета) → секции `<section class="section">` с `<h2 class="section__title">` и текстом в `<div class="prose">` → блок «См. также» `<div class="see-also">` (2–4 ссылки на страницы сайта) → `<footer class="footer">` с блоком «Источники» (3–6 ссылок: ru.wikipedia.org + тематические сайты).
5. Объём: **не менее 4000 байт** осмысленного текста на страницу, 4–6 секций h2. Для бога: Происхождение и образ · Иконография · Культ и мифы · Место в загробной вере / связи · Интересные факты.
6. Ссылки — только на файлы из карты выше и внешние (Википедия и т.п.). Никаких мёртвых внутренних ссылок. Никаких `lorem`.
7. Факты — по Википедии (ru) и авторитетным сайтам; даты и имена сверять (например: Джосер ~2670 до н.э., Хеопс ~2560 до н.э.). Даты писать «до н. э.».
8. После записи партии: прогнать `python3 ~/Projects/egypt/scripts/check_links.py`, починить своё, записать строку в `chip_log.md`: дата | партия | файлы | замечания.
